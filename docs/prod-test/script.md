# 换个老板｜第1集

原创都市逆袭漫剧，8镜×6秒＝48秒。两名成年虚构角色，一个会议室。

被上司夺走署名的方案作者，亮出新股东身份夺回主动，却发现打压背后另有其人。

## E01S01｜6秒｜中景双人侧背

顾衡用右手把无字文件夹沿桌面推向林澈。

台词：你的名字，不配在上面。

运镜：固定机位，略低视点；情绪：傲慢施压。连续性：文件夹初始在右侧；两人站立；林澈在左、顾衡在右。

## E01S02｜6秒｜林澈侧面中景，顾衡右肩作前景

林澈用左手按住面前的文件夹。

台词：方案是我做的。

运镜：极慢推近；情绪：克制坚定。连续性：文件夹停在左侧，不换手；顾衡仍在右侧。

## E01S03｜6秒｜顾衡侧面中景，林澈左肩作前景

顾衡抬起右手食指指向桌面。

台词：成果，归公司。

运镜：固定机位；情绪：轻蔑。连续性：文件夹仍在林澈左手下；右手戒指不变。

## E01S04｜6秒｜林澈侧背中景

林澈将左手从文件夹上缓缓收回。

台词：那就先换个老板。

运镜：缓慢低位推近；情绪：平静反击。连续性：文件夹静止在左侧；两人均站立；不越轴。

## E01S05｜6秒｜顾衡侧面中景

顾衡把指向桌面的右手收回身侧。

台词：你什么意思？

运镜：固定机位；情绪：惊疑。连续性：文件夹仍在左侧，无新道具；保持顾衡右侧。

## E01S06｜6秒｜林澈左侧三分之二侧背，双人中远景

林澈沿桌边向主位迈出一步。

台词：这家公司，我买了。

运镜：缓慢上升数厘米的低角度推近；情绪：从容掌控。连续性：只迈一步；文件夹留在桌面左侧；顾衡右侧静止，以空间变化表现权力反转。

## E01S07｜6秒｜顾衡侧面中景，林澈左背影前景

顾衡向林澈微微低头。

台词：我道歉，还来得及吗？

运镜：极慢推近；情绪：失势恳求。连续性：林澈在前镜迈出一步的位置；不夸张跪地；文件夹未动。

## E01S08｜6秒｜林澈侧背中景，左墙玻璃门进入画面

林澈将视线转向左侧玻璃门。

台词：叫你背后的人来。

运镜：缓慢向左横移数厘米；情绪：冷静追问，悬念。连续性：顾衡仍在右后景，不添加第三人；门外只有模糊光线，不出现新角色。

角色外观锚点：

林澈：原创虚构东亚成年女性，约30岁，清瘦匀称，椭圆脸，黑色低发髻，右侧一缕贴脸碎发，米白色无标志西装外套、深青色高领内搭、黑色直筒裤，左胸银色细月牙胸针，神态沉稳

顾衡：原创虚构东亚成年男性，约38岁，中等结实体型，方脸、浓直眉、整齐黑色侧分短发，无胡须，炭灰色无标志西装、白衬衫、暗酒红色领带，右手银色素圈戒指

空间：黄昏的高层玻璃会议室，长条深色胡桃木会议桌从前景延向后方，后墙落地窗可见没有标识的城市楼群，左墙磨砂玻璃门，右墙深青色墙面，暖琥珀色条形吊灯。林澈始终在画面左侧，顾衡始终在画面右侧。桌面仅有一只无字深青色文件夹。

反转在第6镜，给第7镜完整的失势反应，第8镜留幕后人物钩子。台词作为画外侧背配音，不要求嘴型。

剧本自检：前3秒冲突通过；8镜每镜单一动作通过；每镜6秒符合用户修订通过；角色外观锚点统一通过；结尾悬念通过；台词镜头无正脸大特写通过；每镜最多2人、每句最多15字通过。多角色共用audition_01（遵循当前仓库声线限制），如实作为限制记录。
